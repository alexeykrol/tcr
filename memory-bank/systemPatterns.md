# System Patterns

## Архитектура
- Контентно-ориентированный репозиторий.
- Индекс (`INDEX.md`) управляет навигацией по главам.

## Ключевые паттерны
- Разделение контента по языкам: `chapters/` и `chapters_en_us/`.
- Все ответы должны ссылаться на выбранные главы.
- Если данных в главах нет — возвращается явное сообщение об отсутствии ответа.

## Критические пути
- Выбор релевантных глав через `INDEX.md`.
- Чтение текста глав из `chapters/` или `chapters_en_us/`.
