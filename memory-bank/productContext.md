# Product Context

## Зачем проект существует
Проект упрощает навигацию по книге: вместо чтения всего текста пользователь быстро находит нужные темы через индекс и обращается к конкретным главам.

## Проблемы, которые решает
- Сложно быстро найти нужный фрагмент в большой книге.
- Нужна единая карта тем и глав.
- Нужна поддержка RU/EN контента.

## Как должен работать
- Пользователь определяет тему запроса.
- Через `INDEX.md` выбирает 1–3 релевантные главы.
- Ответы формируются строго на основе выбранных глав.

## UX цели
- Быстрая ориентация по темам.
- Прозрачные ссылки на главы.
- Минимум двусмысленности: если ответа нет — это явно сообщается.
