# Project Brief

## Project
**TCR Navigator** — текстовый репозиторий с индексом и главами книги (Markdown), предназначенный для навигации по темам и быстрого выбора релевантных глав.

## Цели
- Дать четкий индекс по темам и главам.
- Обеспечить быстрый поиск и ссылку на нужные главы.
- Поддерживать русскую и английскую (en-US) версии глав.

## Объем проекта
- Файлы глав в `chapters/` (RU) и `chapters_en_us/` (EN).
- Индекс и инструкция по использованию в `INDEX.md`.

## Ключевые ограничения
- Контент — в Markdown.
- Ответы/сводки должны опираться **только** на главы, указанные в индексе.
- Не придумывать тезисы вне текста глав.
